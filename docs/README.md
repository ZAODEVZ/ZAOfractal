## How the numbers work

Every on-chain figure in every document here is measured from one committed
snapshot of OP Mainnet in [`data/`](../data/), and held as an expectation in
[`scripts/verify-claims.mjs`](../scripts/verify-claims.mjs).

```bash
node scripts/pull-data.mjs        # refresh the snapshot from chain
node scripts/verify-claims.mjs    # re-check every quoted figure; non-zero on drift
```

A figure that moves fails the check rather than aging quietly into a falsehood.
That property was added after a v0.2 accuracy pass found the whitepaper
asserting a participation rate, a Gini coefficient and a transaction count that
the chain contradicted.

The checks also guard a small number of **sentences**, not just numbers - the
language recording that a named facilitator bench has not been contacted and
has agreed to nothing. A later edit that trims it fails the run.
